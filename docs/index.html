AGY Easy Install

Unofficial Google Antigravity setup by wtg-codes

Before You Start

  • You need a terminal — any Linux or macOS terminal will work.
  • Use a consumer Gmail account to sign in to Antigravity (not a school or work account).
Corporate / CloudTop Users
  • Environment: Spin up a Linux CloudTop via internal corp tools and wait until you reach the graphical desktop.
  • Account: You MUST use a consumer Gmail account — your corporate account will not work. Have your password and 2FA device ready.
1

Open Your Terminal

Open a terminal on your machine:

  • • Linux: Press Ctrl + Alt + T, or search for "Terminal"
  • • macOS: Open Terminal.app from Applications → Utilities, or press ⌘ + Space and type "Terminal"
2

Copy the Install Command

Click the button below to copy the automated installation script. This single command downloads the installer and runs it entirely in memory—no extra execution permissions required!

curl -fSsL "https://raw.githubusercontent.com/wtg-codes/agy-easy-install/main/antigravity-manager.sh" | bash
3

Choose What to Do

Go back to your terminal, paste the command (Ctrl + Shift + V on Linux, ⌘ + V on macOS), and press Enter.

The script detects your system and shows a simple menu. Use arrow keys to navigate and Enter to select.

Wizard Flow:

💡 The script asks what you need, then auto-selects the best options for your system.

🎓 Set up for lab (recommended)

One click installs both the IDE and CLI using the best method for your system. No decisions needed!

⚡ Install or update a specific tool →

  • 1
    Antigravity IDE

    Launches the method selector (Homebrew, System Repo, or Official Binary) to install the GUI IDE.

  • 2
    Antigravity CLI (agy)

    Installs the command-line helper tool (standalone, no IDE required).

  • 3
    Antigravity SDK (Python)

    Installs the official Python package google-antigravity via pip.

  • 4
    Antigravity Dev Box (agy-box v0.6.0)

    Turnkey Distrobox sandbox container packaging an isolated environment with full graphical desktop accessible via noVNC (http://localhost:6080) and AI dashboard via Open WebUI (http://localhost:8080). Install via CLI flags --install-sandbox or --install-agy-box.

Modern IDE Support (VS Code, JetBrains, Zed)

Prefer working inside your existing editor? Install official and community Antigravity companion extensions directly using modular CLI flags:

VS Code & Insiders --install-vscode

Installs Antigravity tools into VS Code or VS Code Insiders via code --install-extension.

JetBrains IDEs --install-jetbrains

Integrates plugin support across IntelliJ IDEA, PyCharm, WebStorm, and Android Studio.

Zed Editor --install-zed

Configures language servers and assistant extension definitions for high-performance Zed workflows.

All Detected Editors --install-extensions

Auto-detects installed editors on your system and equips all of them in a single command.

Antigravity cleanup options →

Uninstall Antigravity, save/remove the manager script, or launch Demo UI to try the installer in sandbox mode.

Launch Antigravity

You're all set! You can now launch Google Antigravity from your application menu, desktop shortcut, or by typing antigravity in your terminal.

Fallback: Running from the Terminal

If the icons don't appear right away, you can always launch it from your terminal by typing:

antigravity

If it says "command not found", close and reopen your terminal to refresh your system path, then try again.

Where are my files? • Workspace: ~/my-antigravity-work
• Homebrew: Managed by brew.
• System Repo (APT/DNF): Installed system-wide.
• Official Binary: Installed to ~/.local/lib/antigravity or /Applications.

Need the Antigravity CLI? (New)

Install the command-line helper tool agy directly using the command:

curl -fSsL "https://antigravity.google/cli/install.sh" | bash

Or select Antigravity CLI from the interactive installation menu.

Need the Official Binary directly?

If the installer doesn't support your system, download the standalone package manually:

Linux (x64) macOS (Apple Silicon) macOS (Intel) Windows (x64)

These links are updated nightly by our CI pipeline.

Managing Your Installation

The script automatically saved a management tool to your system! If you ever need to uninstall the IDE, switch installation types, or force an update, just open a terminal and type: antigravity-manager
